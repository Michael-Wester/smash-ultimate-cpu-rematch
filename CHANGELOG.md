# Changelog

## 0.5.0 — 2026-11-01

Initial repository release. Confirmed by the project owner on their Windows/Eden
setup with Smash Ultimate 13.0.3 for mid-match restarts and rematches during GAME!.

- Restart a regular local 1v1 CPU match using Switch L + R + Y.
- Keep the current match setup and skip character/stage selection.
- Check the exact game version and executable layout before installing hooks.
- Support relocated state pointers and vtables in read-only or writable module data.
- Use separate 8-byte mode output buffers and validate retry-chain memory.
- Prevent repeat activation while the shortcut is held.
- Include bounded diagnostics, a read-only retry preflight, source and build scripts.
- Include host regression tests and execution tests for the compiled AArch64 NRO.
